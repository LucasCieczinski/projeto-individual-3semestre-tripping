# TripPing

Projeto individual do terceiro semestre com o tema **Turismo**. O repositório contém o front-end React e a API REST Spring Boot.

```text
projeto-individual-3semestre-tripping/
├── trip-ping-web/    # React e CSS Modules
└── tripping.app/     # Java, Spring Boot e JdbcTemplate
```

## Executar

1. Crie o banco PostgreSQL `tripping`.
2. Configure e inicie o back seguindo `tripping.app/README.md`.
3. Configure e inicie o front seguindo `trip-ping-web/README.md`.
4. Abra `http://localhost:5173`.
